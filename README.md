# Documentation
Diagrams, Contracts, Requirements

### ¿Qué se guarda aquí?

En este repositorio se almacenan el OpenApi/swagger de cada microservicio, la documentación consolidada como requerimientos del microservicios y diagramas.

### ¿Qué se coloca en la wiki?

La wiki del repositorio GitHub contiene los estándartes de integración y contratos del sistema, matriz de roles y permisos, aclaraciones de uso y guia por cada microservicio para proveer un punto central de información para todos los equipos, teniendo así, un entendimiento global del proyecto.
